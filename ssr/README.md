# Photosphere v3 SSR Web Gallery

Nuxt 4 + Quasar + Firebase web gallery serving media and metadata strictly via authenticated SSR proxy endpoints.

## Architecture

- **Configuration (`server/utils/photosphere-config.ts`, `server/plugins/00.photosphere-config.ts`)**: Reads and validates root `photosphere.config.json` (generated by `make init`) during `pnpm dev`, `pnpm build`, and container startup, failing fast if absent or malformed while allowing explicit `process.env.*` overrides.
- **Auth Gate (`server/middleware/auth.ts`)**: Every `/api/*` request except public `/api/healthz` requires a valid `Authorization: Bearer <firebase_id_token>`, `email_verified === true`, and case-insensitive membership in `ALLOWED_EMAILS` (`ADMIN_EMAIL` for admin routes) **before** touching in-memory caches or `/mnt/photosphere`.
- **Dual-Bucket GCS Proxy**:
  - `PHOTOSPHERE_DATA_BUCKET` (`STANDARD`): serves/persists `photosphere_database_cloud.json` (flat SHA-1 map), `<lang>_photosphere_image_labelling_database_cloud.json`, `<lang>_photosphere_image_caption_database_cloud.json`, and `photosphere_albums.json`.
  - `PHOTOSPHERE_MEDIA_BUCKET` (`ARCHIVE`): serves originals and `thumbnails/` with HTTP `Range` (`206 Partial Content`) streaming via `/api/img/[...path]`.
- **Isolated Disk Caches**: `thumbnail-cache/` (30-day default TTL) is isolated from `media-cache/` (12-hour default TTL) so browsing small thumbnails never evicts cached originals/videos or triggers extra `ARCHIVE` egress.
