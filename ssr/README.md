# Photosphere v3 SSR Webapp

Mobile-first, desktop-capable Nuxt 4 + Firebase + Google Cloud Storage media application built with Tailwind CSS v4, `shadcn-vue` (`reka-ui`), `lucide-vue-next`, and Pinia.

## Architecture

- **Configuration (`server/utils/photosphere-config.ts`, `server/plugins/00.photosphere-config.ts`)**: Reads and validates root `photosphere.config.json` (generated by `make init`) during `pnpm dev`, `pnpm build`, and container startup, failing fast if absent or malformed while allowing explicit `process.env.*` overrides.
- **Dual Auth & Request Correlation (`server/middleware/00.request-logger.ts`, `server/middleware/auth.ts`, `server/services/auth.service.ts`)**:
  - Public probes: `/api/healthz`, `/api/readyz`, and `DELETE /api/auth/session`.
  - JSON & mutation APIs require `Authorization: Bearer <firebase_id_token>`, `email_verified === true`, and case-insensitive membership in `ALLOWED_EMAILS` (`ADMIN_EMAIL` for admin routes).
  - Media streaming (`GET /api/media/[hash]`) accepts either Bearer tokens or an `HttpOnly; SameSite=Lax` signed session cookie (`__ps_media`) minted via `POST /api/auth/session`, allowing native `<img>` and `<video>` caching and HTTP `Range` (`206 Partial Content`) streaming without exposing tokens in URLs.
- **Server APIs**:
  - `GET /api/me`: returns signed-in email and role capabilities (`isAdmin`, `canEditAlbums`).
  - `POST / DELETE /api/auth/session`: mints/clears the `__ps_media` cookie for media proxy reads.
  - `GET /api/files` & `GET /api/files/[hash]`: paginated, filtered, and indexed media queries (`q`, `fileType`, `dateFrom`, `dateTo`, `memoryDate`, `album`, `notInAlbum`, `lat`/`lng`/`radiusKm` via Haversine distance).
  - `GET /api/media/[hash]?variant=thumbnail|source`: streams media backed by `Cache-Control: private, max-age=31536000, immutable`, `ETag`, `206` byte-range support, and a bounded LRU disk cache under `runtimeConfig.storage.mountedVolumePath`.
  - `GET /api/search/suggestions`: unified label and caption autocomplete with `en` fallback.
  - `GET /api/location/search`: LRU-cached, 1 req/sec rate-limited OpenStreetMap Nominatim proxy.
  - `GET / POST /api/albums` & `GET / PATCH / DELETE /api/albums/[albumName]`: paginated album summaries and conflict-safe writes to `photosphere_albums.json` using a serialized write mutex and GCS `ifGenerationMatch` preconditions.
  - `POST /api/admin/refresh-database?lang=en` & `GET /api/database?lang=en`: admin-only forced reload and diagnostic JSON snapshot.
- **Frontend (`app/`)**:
  - Follows `docs/designs/frontend-design-system.md` (semantic light/dark CSS tokens with anti-FOUC head script, deterministic varied-row-span CSS Grid masonry, and a 3-tier `ui/` -> `common/` -> `organisms/` component hierarchy).
  - Routes: `/login`, `/` (Photos gallery & search/filters), `/memories` (On This Day), `/albums`, `/albums/[albumName]`, and `/settings`.
